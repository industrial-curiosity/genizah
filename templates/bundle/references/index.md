# {{BUNDLE_TITLE}} references

References and implementation samples are optional. Samples are illustrative,
non-normative supporting material, never required acceptance or conformance
tests. Include sources or samples only with express user consent. Without that
consent, remove this file and the bundle index's `References` section.

With consent, replace this guidance with links to the approved reference
concepts. Every retained raw sample requires a linked `Reference` concept that
explains its purpose, provenance, and license when known.

## Optional reference concept template

Create a separate Markdown concept for an approved source using this shape.
Replace all markers, and include only details covered by the user's consent.
